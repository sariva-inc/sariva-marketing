# Sariva marketing site

Professional landing page for Sariva — an AI operations layer for Kafka, Flink, Confluent Cloud, and cloud-native streaming infrastructure.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Main files

- `app/page.tsx` — complete landing page layout and content
- `app/layout.tsx` — metadata, fonts, analytics wrapper
- `app/globals.css` — global Tailwind tokens and base styles

## Design direction

The page uses a dark enterprise SaaS visual system with a cleaner hero, product console mockup, structured capability cards, security positioning, and a stronger contact section.
